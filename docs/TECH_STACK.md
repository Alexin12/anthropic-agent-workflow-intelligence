# Tech Stack

- **Frontend:** React and TypeScript.
- **Backend:** FastAPI and Python, managed with `uv`.
- **Database:** PostgreSQL with `pgvector` for relational data, full-text search, and vector search.
- **Infrastructure:** Docker Compose for PostgreSQL; frontend and backend run locally on the host.
- **API:** HTTP REST API between the frontend and backend.
- **Local processing:** Local models and embeddings; corpus data and project configuration stay local and are never uploaded.
