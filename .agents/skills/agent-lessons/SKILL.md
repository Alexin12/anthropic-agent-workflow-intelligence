# Agent Lessons

Use this skill to keep project-specific workflow knowledge in one short, reviewable note.

## Before work

1. Read [`docs/agents/lessons-learned.md`](../../../docs/agents/lessons-learned.md).
2. Apply every lesson relevant to the current task.
3. Mark a lesson not applicable only when the current task provides evidence that it does not apply.

Completion check: every relevant lesson is either applied or explicitly marked not applicable.

## Record a lesson

1. Confirm the root cause with observable evidence.
2. Check the note for an existing entry covering the same root cause.
3. Add one concise entry with `Failure`, `Evidence`, `Prevention`, and `Validation`.
4. Keep the entry in English and preserve the note's existing structure.

Completion check: the note has one canonical entry, and the pointer in `AGENTS.md` still resolves.
